# Atividade 03 Sistemas Distribuídos

## Serviços

1. [Serviço de Lances (bid-srv)](#serviço-de-lances);
2. [Serviço de Leilão (auction-srv)](#serviço-de-leilão);
3. [Serviço de Pagamentos (payment-srv)](#serviço-de-pagamentos);
4. [Serviço Externo de Pagamentos (payment-ext-srv)](#serviço-externo-de-pagamentos);
5. [Gateway API](#gateway-api)

### Serviço de Lances

- **Funções:** Gerenciamento dos lances: Criação e validação;

### Serviço de Leilão

- **Funções:** Gerenciamento dos leilões: Criação, inicialização e finalização;

### Serviço de Pagamentos

- **Funções:** Gerenciamento dos pagamentos realizados pelos ganhadores dos leilões;

### Serviço Externo de Pagamentos

- **Funções:** Simula um sistema externo de pagamento que deve ser integrado com o sistema de leilão desenvolvido;

### Gateway API

- **Funções:** Fornece as informações ao frontend
